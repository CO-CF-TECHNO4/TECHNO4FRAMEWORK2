# Документаційні ресурси генерації CLI: Tabs Cordova Android Demo

Цей каталог містить моноширинні текстові копії термінального виводу, згенеровані під час створення та верифікації тестового застосунку з шаблоном **Tab Views** та підтримкою **Cordova Android** за допомогою глобально встановленого пакунка **`techno4-cli`** (`v2.0.0`).

---

## 📁 Завантажувані файли термінального виводу (Plain Text Resources)

| Файл | Опис | Формат | Посилання для завантаження / перегляду |
| :--- | :--- | :--- | :--- |
| **`cli-generation-output.txt`** | Повний лог інтерактивного діалогу, спінерів та виконання генерації проєкту | Моноширинний текст (ASCII/UTF-8) | [`cli-generation-output.txt`](./cli-generation-output.txt) |
| **`cli-project-structure.txt`** | Повна візуальна деревоподібна структура згенерованого каталогу `cli-demos/` | Текстове дерево файлів (ASCII tree) | [`cli-project-structure.txt`](./cli-project-structure.txt) |
| **`cli-cordova-android.txt`** | Звіт підсистеми Cordova: встановлена платформа `android 15.1.0`, плагіни та `config.xml` | Консольний звіт | [`cli-cordova-android.txt`](./cli-cordova-android.txt) |
| **`cli-build-verification.txt`** | Лог успішної збірки Vite (`npm run build`), розміри чанків та трансформованих модулів | Лог компілятора | [`cli-build-verification.txt`](./cli-build-verification.txt) |

---
