# ТЕХНІЧНЕ ЗАВДАННЯ: TECHNO4FRAMEWORK2 (v2.0)

## 1. Загальний опис та мета проєкту

**TECHNO4FRAMEWORK2** — це нове покоління уніфікованого фулстек-фреймворку для створення високопродуктивних клієнтських додатків (Mobile, Desktop, Web) та реактивних бекенд-систем реального часу.

Фреймворк не копіює сліпо ні Apple, ні Google. Його мета — створити **власну незалежну дизайн-систему та платформу (Techno4 Design System)**, увібравши найкращу ергономіку та механіки з iOS та Android, але отримавши самобутній стиль, адаптований під високотехнологічні інтерфейси (аудіо-синтезатори, системи керування робототехнікою, складні веб-додатки).

### Базові опори проєкту:
1. **Клієнтське ядро (Techno4 Core)**: на базі імпорту свіжого ядра **Framework7 (v9)** у неймспейсі **`techno4`**, очищене від сторонніх фреймворків (React/Vue/Svelte).
2. **Збереження та аудит наявних тем (iOS та MD)**: теми iOS та Material **не випилюються поспіхом**, а залишаються в кодовій базі як джерело механік та стилів. Формується поетапний план синтезу власної теми **Techno4 Theme**.
3. **Серверна частина (Headless Total.js v5 Backend)**: екосистема **Total.js v5** (`techno4-framework2-total`) без власної промальовки UI (jComponent / Tangular). Рендерингом 100% інтерфейсу займається Techno4 Core.
4. **Візуальний подієвий рушій (Dataflow Engine)**: **`techno4-framework2-threads`** — перейменований та інтегрований рушій **Total.js Flow v11 (FlowStream)**.

Всі вихідні коди, структура модулів та інструменти розробки нового покоління розміщуються у новому підкаталозі кореня проєкту:  
📁 `/TECHNO4FRAMEWORK2`

## 2. Ключові стратегічні рішення та архітектурні зміни

### 2.1. Стратегія побудови власної теми (Techno4 Design System)
Замість сліпого копіювання iOS чи Android та замість поспішного видалення стилів, впроваджується **План синтезу тем**:
* **Збереження обох тем на першому етапі**: Усі файли стилів `-ios.less` та `-md.less` залишаються в репозиторії недоторканими, щоб не втратити жодної напрацьованої деталі.
* **Що береться з iOS**:
  - Плавні жести (інтерактивний свайп назад з інерцією, гумовий pull-to-refresh).
  - Модальні шторки (Sheet Modals) з підтягуванням знизу.
  - М'яке підсвічування при тапі (Touch Highlight) без важких анімацій.
  - Лаконічна типографіка, відсутність візуального сміття, іконкова навігація.
  - Розмиття фону (Backdrop Blur / Glassmorphism) для системних панелей.
* **Що береться з Android (Material You / MD3)**:
  - Floating Action Buttons (FAB) з можливістю розкриття швидких дій (Speed Dial).
  - Зручні висувні панелі (Navigation Drawers).
  - Гнучкі динамічні тони поверхонь на базі токенів CSS Variables.
  - Інформативні спливаючі повідомлення (Snackbars / Toasts) з кнопками дій.
  - Багаті компоненти введення (повзунки Range Slider із числовими бульбашками, пікери дат/часу).
* **Власний стиль Techno4**:
  - Щільні інформативні лейаути (для дашбордів телеметрії роботів та звукових студій).
  - Спеціалізовані елементи: поворотні енкодери (knobs), слайдери-фейдери, матричні кнопки.
  - Глибока темна тема за замовчуванням із неоновими/технологічними акцентними кольорами.

---

### 2.2. Повна ліквідація залежності від macOS та перехід на Fontello (Zero-build icons)
* Повна відмова від генерації іконок під час збірки:
  - Видалення скриптів Python 2, `fontforge` та `ttf2woff`.
  - Використання готових pre-compiled шрифтів іконок (`woff2`, `woff`, `ttf`), які вже є в проекті.
  - Подальше додавання іконок — виключно через стандартизований воркфлоу **Fontello** (збереження конфігу та згенерованих файлів).
* Усі файлові операції збірки переведено на нативний API Node.js (`fs.rmSync`, `fs-extra`).
* Гарантована нативна збірка на: **Windows 10/11**, **Linux**, **macOS**.

---

### 2.3. Очищення від React, Vue, Svelte (Виключно чистий Core)
* Повне видалення коду та конфігурацій `src/react`, `src/vue`, `src/svelte`.
* Розвиток виключно **Techno4 Core** (vanilla JS, Single-File Components, реактивний Store, DOM64).

---

### 2.4. Переписування Techno4-CLI на Techno4 Core
* Графічний інтерфейс конфігуратора CLI (`ui/`) переписується з Vue 3 на чистий **Techno4 Core**.
* Генерація проектів оптимізується під чистий Techno4 Core + Vite + Cordova 12+.

---

### 2.5. Headless Total.js v5 (Заміна UI-рендерингу на Techno4)
* Повне видалення jComponent / Tangular з Total.js.
* Total.js відповідає виключно за **Total Actions, Schemas, WebSocket / SSE transport**.
* 100% UI рендериться ядром Techno4 Core.

---

### 2.6. Threads Studio як View всередині Boonker
* Рушій **`techno4-framework2-threads`** (адаптований Flow v11) інтегрується в головний застосунок `apps/boonker`.
* **Threads Studio** реалізується як **окремий View (панель/вкладка)** усередині Boonker.
* **Перехідний стан**: полотно Threads на першому етапі зберігає поточні елементи, з подальшим поступовим переписуванням нод на рендерер Techno4 Core.

---

### 2.7. Підтримка сучасної Apache Cordova (Cordova 12+)
* Підтримка **Cordova CLI 12+** та `cordova-android@12/13+`.
* Цільові рівні Android SDK: **API 33, 34, 35** (Android 13 / 14 / 15).
* Нативний **Android SplashScreen API** (без застарілих плагінів).
* Оновлений Content Security Policy (CSP) для безперебійного зв'язку з сокетами Total.js та Threads.

---

### 2.8. Економія токенів та залучення Грока для масових операцій
* Рутинні та громіздкі задачі (масовий рефакторинг файлів, синтаксична заміна токенів у десятках компонентів, індексація коду в Qdrant) автоматизуються локальними скриптами на Node.js та делегуються **Гроку (OpenClaw)**.
* Основний контекст тримається лаконічним і сфокусованим на архітектурі та контролі якості.
