# THEME_SYNTHESIS_PLAN.md - План синтезу теми Techno4

Цей документ визначає практичний план створення самобутньої дизайн-системи **Techno4 Theme**, яка об'єднує ергономічні досягнення iOS та Android без їхнього сліпого копіювання, з акцентом на високотехнологічні додатки (синтезатори, системи робототехніки, IoT-дашборди).

---

## 1. Базовий принцип: Нічого не видаляти наосліп

1. **Повне збереження початкових стилів**:
   - Файли `[component]-ios.less` та `[component]-md.less` залишаються в каталогах компонентів.
   - Вони слугують еталонною базою міксинів, параметрів та фізики взаємодій.
2. **Паралельна розробка нової теми**:
   - Створюється `src/core/less/techno4-theme.less` та компоненти отримують секції/файли специфічні для `techno4`.
   - В ядрі підтримується перемикач: можна явно запустити перегляд `theme: "ios"`, `theme: "md"` або нашої нової `theme: "techno4"`.

---

## 2. Матриця відбору механік та елементів

| Категорія | Джерело: iOS | Джерело: Android (MD3) | Специфіка Techno4 |
| :--- | :--- | :--- | :--- |
| **Жести та навігація** | **БЕРЕМО**: Плавний інтерактивний свайп назад (`swipeBack`), гумова інерція прокрутки, Pull-to-Refresh. | **БЕРЕМО**: Navigation Drawer (бічна шторка меню), швидкі переходи між екранами без зайвих затримок. | Можливість блокування жестів на окремих інтерактивних зонах (XY-пади, повзунки синтезатора). |
| **Зворотний зв'язок (Feedback)** | **БЕРЕМО**: М'який `touchHighlight` (миттєвий контрастний стан без затримки кадру). | **БЕРЕМО**: `touchRipple` (ефект хвилі для пласких кнопок та карток дій). | Тактильний "клік" і підсвічування стану для апаратних/віртуальних тумблерів та енкодерів. |
| **Модальні вікна** | **БЕРЕМО**: `Sheet Modal` (шторка знизу, що тягнеться пальцем) та `Action Sheet`. | **БЕРЕМО**: Діалогові вікна з чіткими кнопками підтвердження, Snackbars (тоасти з діями). | Плаваючі вікна-панелі (HUD / Floating Inspector) для візуального редактора Threads. |
| **Палітра та поверховість** | Чистий розмитий фон (`backdrop-filter: blur()`), напівпрозорі панелі Navbar/Toolbar. | **БЕРЕМО**: Тональні шари поверхні (Surface Tonal Palette) замість брудних тіней. | Глибока графітова основа (`#0d0e12`), неонові статус-індикатори (Cyber Cyan, Signal Orange, Pulse Green). |
| **Кнопки та контролери** | Сегментовані перемикачі (Segmented / Pill-tabs), компактні тогли. | **БЕРЕМО**: Floating Action Button (FAB) з меню Speed Dial. | Ротаційні регулятори (**Knobs**), вертикальні фейдери, матричні кнопки (Pad triggers). |

## 3. Етапи впровадження

1. **Етап 1 (Аудит і стабілізація)**:
   - Забезпечити безпомилкову збірку компонентів з обома наявними темами через кросплатформний Vite/Rollup.
2. **Етап 2 (Формування базових CSS-змінних Techno4)**:
   - Описати системні CSS Custom Properties для нової теми в `src/core/less/techno4-vars.less` (шрифти, радіуси заокруглення, акцентні кольори, відступи).
3. **Етап 3 (Синтез у Boonker)**:
   - Додати в додаток Boonker перемикач тем (iOS / MD / Techno4), щоб візуально порівнювати кожен компонент пліч-о-пліч і доводити ергономіку до ідеалу.
