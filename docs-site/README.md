# Techno4 Framework - Окрема секція документації сайту

Ця директорія призначена для автономної роботи з документацією сайту [techno4.online](https://techno4.online/%D0%BD%D0%B0%D0%B4%D0%B1%D0%B0%D0%BD%D0%BD%D1%8F/%D1%84%D1%80%D0%B5%D0%B9%D0%BC%D0%B2%D0%BE%D1%80%D0%BA).

## Призначення та ізоляція:
- Ця секція **є повністю локальною** та ізольованою від основного монорепозиторію `TECHNO4FRAMEWORK2` (внесена до кореневого `.gitignore`).
- Вона призначена для відстеження **окремим Git-репозиторієм** документації.
- Взаємодія, завантаження та публікація статей документації здійснюється через API сайту за допомогою API ключа.

## Налаштування API:
Створіть файл `.env` на основі `.env.example`:

```env
TECHNO4_DOCS_API_URL=https://techno4.online/api/v1
TECHNO4_DOCS_API_KEY=your_api_key_here
TECHNO4_DOCS_CATEGORY_ID=11
```
