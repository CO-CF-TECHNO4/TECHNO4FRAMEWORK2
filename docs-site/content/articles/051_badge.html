Бейдж

Бейджі використовуються для відображення/позначення чисел і міток на різних елементах вашого застосунку.

Макет бейджа

Бейджі мають надзвичайно простий макет, це просто елемент із класом ‘badge’:
<span class="badge">32</span>

Кольори бейджів

Бейджі підтримують усі кольори за замовчуванням:
<!-- Зелений бейдж -->
<span class="badge color-green">32</span>

<!-- Червоний  бейдж -->
<span class="badge color-red">15</span>

Змінні CSS

Нижче наведено список пов’язаних змінних CSS (спеціальні властивості CSS).
:root {
  --t4-badge-text-color: #fff;
  --t4-badge-bg-color: #8e8e93;
  --t4-badge-padding: 0 4px;
  --t4-badge-in-icon-size: 16px;
  --t4-badge-in-icon-font-size: 10px;
  --t4-badge-font-weight: normal;
  --t4-badge-font-size: 12px;
}

  --t4-badge-font-weight: 600;
}
