Techno4 CLI

Рекомендований спосіб почати роботу з новою програмою Techno4 – використовувати Techno4 CLI, вона надає найповнішу кількість комбінацій із різними шаблонами, цільовими пристроями/платформами, фреймворками та деякими найкращими практиками.

Готові до використання шаблони

Ви також можете ознайомитися з розділом шаблонів початкової програми та інструментів, щоб почати відразу з попередньо налаштованої програми.

Ручне встановлення

Ми можемо завантажити (встановити) Techno4 з NPM: 
$ npm install Techno4
