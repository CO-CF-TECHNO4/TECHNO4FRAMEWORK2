Techno4 CLI — Інтерактивний генератор

Офіційний консольний інструмент techno4-cli — це найшвидший і рекомендований спосіб створення нових проєктів. Він містить готові пресети шаблонів (вкладки Tabs, бічні панелі Split View, порожній проєкт), підтримку компілятора Vite з гарячою заміною модулів (HMR), інтеграцію мобільної платформи Apache Cordova Android 15.1.0 та набір іконок t4-icons.
# Встановлення інструменту глобально в систему
npm install -g techno4-cli

# Створення нового проєкту за допомогою інтерактивного майстра
techno4 create

Ручне встановлення у готовий проєкт

Якщо у вас вже є налаштований вебпроєкт на базі Vite, Rollup або Webpack, ви можете додати бібліотеки ядра TECHNO4 безпосередньо з npm-реєстру:
# Встановлення ядра інтерфейсу та DOM-рушія
npm install techno4 dom64

# Встановлення плагіна компілятора компонентів для Vite / Rollup (опціонально)
npm install -D rollup-plugin-techno4

Підключення та ініціалізація в коді

Для використання повного набору компонентів імпортуйте збірку bundle та відповідні таблиці стилів у вашому головному файлі (наприклад, src/js/app.js):
// Імпорт стилів теми Techno4 та іконок
import 'techno4/css/bundle';
import 'techno4/icons/css';

// Імпорт ядра фреймворку
import Techno4 from 'techno4/bundle';

// Ініціалізація додатку
