Розкладка “Справа наліво”

Techno4 має повну підтримку мов справа наліво (справа наліво), таких як арабська та іврит.

Щоб увімкнути режим RTL, вам просто потрібно включити файл CSS зі стилями RTL замість звичайного та додати атрибут dir="rtl" до елемента html:

<!DOCTYPE html>
  <html dir="rtl">
    <head>
      ...
      <title>My App</title>
      <!-- Path to Techno4 RTL stylesheet -->
      <link rel="stylesheet" href="path/to/techno4-bundle-rtl.min.css">

      <!-- Path to your custom app styles-->
      <link rel="stylesheet" href="path/to/my-app.css">
      ...
Зауважте, що всі "дзеркала" RTL у режимі RTL створюються лише за допомогою CSS.

Тому вам не слід змінювати порядок елементів HTML і зберігати його в LTR.
